    How contributions progress

    1. Attendance: an eligible devnet transfer under the published rule. It stays pending until reviewed; it is not proof of skill or identity.
    2. Participation: an eligible pull request to a project's lab fork.
    3. Tested candidate: the exact commit passes the protected validation workflow, including a real Solana runtime fixture on a local validator.
    4. Adoption package: a versioned, hashed manifest of the candidate, its evidence and its risks.
    5. Recognition: an authorised reviewer for that project accepts the exact package.
    6. Reward: a Sol.College contribution credential that names the specific accepted work.

    Verify a credential

    Credentials are platform-published verification records: not accreditations, not on-chain, not cryptographically signed. Revocations stay visible here.

    Data: data.json, generated from public records by a GitHub workflow. Requests go through GitHub issues and are handled asynchronously.
